# ピカソ907枚・ビブロ受領画像 v277

PSG_centered_all.zipをビブロのreceipt.jsonとSHA-256で照合。907枚全件をデコード確認し、画像のバイト列を変更せずZIP_STOREDで128分割保管。元画像・旧版は変更しない。元の対応表と注記をoriginal-metadata/に保存。

manifest.jsonは制作管理番号とは独立した受領パスと画像ハッシュ、実種/姿ID・実寝顔IDとの照合結果を記録する。通常861枚・姿別22枚の計883枚を種/姿/寝顔名の一致で接続。文字正規化はNFKCと前後空白除去のみ。制作管理の寝顔IDや一覧位置、星順から実IDを推定しない。

24枚はpending.jsonに保留：ハロウィン帽子色→年別姿4枚、サイズ未指定バケッチャ/パンプジン7枚、寝顔名不一致13枚。名称の誤記らしきものも推測で自動置換しない。新しい寝顔の星数は受領表にないためマスターへ追加しない。

再生ボタン残り候補356枚は自動除外しない。接続済み画像にも含むため、公開表示を見て気になる画像だけ個別に再加工する。画像が取得できなければ既存のNo image表示を維持。

PSG_sleep_images.pyがビルド時にパック/画像のハッシュと実ID所属を検証してassets/sleep/picasso-v277/へ展開する。公開ページには個々のWebPを外部画像として接続し、ZIPや画像のdata URIをHTMLへ埋め込まない。各パックのアップロードを小さく区切り、生成された907個のWebPをGitHubへ重複送信しない。

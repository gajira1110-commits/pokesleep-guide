# 料理画像マスター

各料理の `image.webp` は料理一覧用の透過128×128px画像です。元画像をHTMLへ埋め込まず、ビルド時に相対パスを登録します。画像の差し替えは同名ファイルを置いて再ビルドします。表示は44px、一覧では遅延読み込みします。

2026-09-30、ユーザーの実機スクリーンショットに写った料理を参照して画像生成ツールで料理ごとにドット絵へ描き直しました。みつあつめチョコワッフルの承認済みサンプルを共通の絵柄参照として使います。とくせんリンゴサラダは名称と料理の説明から描いたイメージです。元ゲームの画像ファイルそのものではありません。

共通指示：料理だけを中央に配置。器・盛り付け・食材の特徴を維持。四角いピクセル、段差のある輪郭、限定パレット、斜め上の視点。背景透過、文字・レベル・数値・画面枠なし。余白約8%。原寸から最近傍で128pxに縮小し、lossless WebPへ書き出しました。

画像の参照資料は各料理の `data.json` の sources と対応するものを使用。image_manifest.json に個別生成指示と元画像を記録します。

# タイプ画像

18タイプは `manifest.json` の英字IDのフォルダーに、各1枚の `icon.png` で管理します。全画面がこの共通画像を参照します。画像変更後は `python PSG_build_master.py` でレビューを再生成してください。

v215（2026-10-01）：ユーザー添付の F5E1A660-9D96-4D80-A272-B3558391A357.jpeg から18種類の円形バッジを分割。文字・罫線・外側背景を除去し、透過128px PNGへ統一。可視領域は112px以内で中央配置し、原画の色・絵柄を維持。切り抜き座標と原本・各画像のハッシュは `artwork.json` に記録しています。

旧18枚は同名ファイルで置換。旧ドット絵シートとその座標データ、旧シートへの実行時フォールバックは削除しました。
